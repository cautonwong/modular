# Loadable image

The Preamble is only the fixed ABI header. A real loader should use an `.emod` container containing header, preamble, text/rodata/data, relocation and import tables, export/service table, dependency/resource/event metadata, and integrity/signature metadata.

Relative entry offsets must be generated by linker/assembler. Do not calculate function-pointer differences in portable C; Cortex-M Thumb state and toolchain ABI matter.

A flat `.bin` is valid only after external references and relocations are resolved, or when the image is completely self-contained.
